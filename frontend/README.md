# Frontend - Online E-Commerce Shopping System

This directory contains the standalone **Frontend Client (Single Page Application)** for the Online E-Commerce Shopping System.

---

## 📁 File Structure
- `index.html`: Main user interface with Product Catalog, Live Search, Category Filter, Shopping Cart Drawer, Simulated Multi-Payment Checkout Modal, Printable Tax Invoice Generator, Order Tracker, and Admin Portal.
- `css/styles.css`: Custom modern styling, CSS variables, gradients, cards, and responsive layouts.
- `js/app.js`: Client-side application logic connecting to the Spring Boot REST API (`http://localhost:8080/api/*`) with automated fallback for offline demonstration.

---

## 🚀 How to Run the Frontend
You can open `index.html` directly in any web browser:
1. Double-click `index.html` (or right-click $\rightarrow$ **Open with Chrome / Edge**).
2. It will automatically load the catalog and communicate with the backend running on `http://localhost:8080`.
