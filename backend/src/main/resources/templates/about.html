Project Overview

Online E-Commerce Shopping System

An enterprise-grade, full-stack online shopping web application built using modern Spring Boot, Thymeleaf templating, Spring Data JPA, and responsive Bootstrap 5 styling.

Robust Architecture

Engineered following the Model-View-Controller (MVC) architectural pattern with clearly separated presentation, business service logic, and database persistence layers.

Complete Shopping Flow

From catalog searching and multi-category browsing to real-time cart calculations (tax, free shipping thresholds) and multi-payment checkout simulations.

Admin Portal & Inventory

Full administrative dashboard equipped with real-time KPI metrics, revenue tracking, low-stock notifications, product catalog CRUD, and live order status management.

Technology Stack

Backend Framework Spring Boot 4.x / Java 21 LTS
Template Engine Thymeleaf 3.1.5
Data & ORM Spring Data JPA / Hibernate
Database H2 In-Memory & MySQL 8.0
